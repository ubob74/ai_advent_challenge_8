# ai_advent_challenge_8

Решение задания "Версии модели" (день 5)

Задача - вычисление скорости падения шара на поверхность.

- task5_v1.mjs - слабая модель (GigaChat-2 Lite)
- task5_v2.mjs - средняя модель (GigaChat-2 Pro)
- task5_v3.mjs - сильная модель (GigaChat-2 Max)

Результат - при первом запуске средняя и сильная модели выдали примерно одинаковый и правильный результат,
при меньшем количестве затраченных токенов (70). Слабая модель при первом запуске вернула неточный результат,
количество затраченных токенов - 250.
При повторном запуске все модели вернули одинаково правильный результат, количество токенов у слабой модели
снизилось до 15, у сильной модели - 17. Средняя модель токены не истратила, вернула сообщение что это демонстрационная модель.
Последующие запуски приводили к снижению количества токенов у слабой модели, а более старшие модели перестали
отдавать информацию о токенах, мотивируя тем что это не связано с запросом.


Вывод - для решения точных (математических) задач следует использовать среднюю или сильную модели,
слабая модель требует некоторого количества повторных обращений, что увеличивает расход токенов,
но в итоге выдает приемлимые результаты.
