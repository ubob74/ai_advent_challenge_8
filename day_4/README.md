# ai_advent_challenge_8

Решение задания "Температура" (день 4)

Задача - вычислить потенциальную энергию медного шара диаметром 1 метр, поднятого на высоту 1 метр

 - task4_v1.mjs - для температуры 0
 - task4_v2.mjs - для температуры 0.7
 - task4_v3.mjs - для температуры 1.2

Все варианты выдавали неоднозначный результат, были как и правильные ответы, так и неправильные.
Использовать для точных вычислений не рекомендую, результат надо перепроверять.
